One deadpan alibi from a robot vacuum for a spot it never cleaned: its log says spot 47 was cleaned at 14:03, its camera says it never left the dock, and it trusts the log — the camera is new here. Running `main.py` prints that exact line to stdout and writes it, with no trailing newline, to `entry.txt`.

## Run it

```sh
python3 main.py
```
